# Лабораторные работы по дисциплине «Операционные системы и сети»

Репозиторий создан для хранения и оформления лабораторных работ
по дисциплине «Операционные системы и сети». Он служит одновременно
рабочей тетрадью — здесь фиксируется ход выполнения каждой работы, —
и портфолио: по содержимому можно проследить, какие навыки
осваивались и как решались практические задачи.

## О дисциплине

«Операционные системы и сети» — дисциплина о том, как устроены и как
администрируются современные операционные системы, а также о базовых
механизмах компьютерных сетей: настройке подключений, удалённом доступе,
сетевых сервисах.

Практическая часть выполняется на виртуальных машинах: это позволяет
в безопасной среде ставить и ломать системы, экспериментировать
с сетевыми настройками и не рисковать основной рабочей системой.

## Что выкладывается в репозиторий

Каждая лабораторная работа размещается в отдельной папке и содержит:

- **README** с полным отчётом: цель работы, описание выполненных шагов,
  пояснения, зачем каждое действие было нужно, и итоги;
- **скриншоты** — доказательства выполнения ключевых шагов (вывод команд,
  конфигурация, результат работы настроенных сервисов);
- при необходимости — конфигурационные файлы и прочие материалы работы.

## Зачем это нужно

- **Закрепление теории практикой.** Темы дисциплины усваиваются надёжнее,
  когда каждая команда выполняется руками и сопровождается пониманием,
  что именно она делает.
- **Навык документирования.** Грамотное оформление результатов — часть
  инженерной работы: отчёты в этом репозитории пишутся так же, как пишется
  техническая документация в реальных проектах.
- **История прогресса.** Репозиторий хранит все работы в одном месте
  с историей изменений — всегда видно, что сделано и когда.

## К какому результату должна привести работа над дисциплиной

Последовательное выполнение лабораторных работ должно сформировать
практические навыки:

1. работы с гипервизорами и виртуальными машинами;
2. установки и первоначальной настройки Linux-систем;
3. администрирования системы через командную строку (пакеты, службы, файлы);
4. настройки сетевых подключений и понимания их принципов;
5. организации удалённого доступа к системам, в том числе по SSH
   с использованием ключей;
6. работы с Git и GitHub как инструментом фиксации и представления
   результатов.

## Структура репозитория

  установка Debian, настройка сети (NAT, Bridged) и SSH-доступа.

Список будет пополняться по мере выполнения новых работ.

# Laboratory Assignments for the "Operating Systems and Networks" Course

This repository is designed to store and document laboratory assignments for the "Operating Systems and Networks" course. It serves both as a workbook—tracking the progress of each assignment—and as a portfolio, showcasing the skills acquired and the methods used to solve practical problems.

## About the Course

The "Operating Systems and Networks" course covers the architecture and administration of modern operating systems, as well as the fundamental mechanisms of computer networks, including connection configuration, remote access, and network services.

Practical tasks are performed using virtual machines, providing a safe environment to set up or even break systems and experiment with network configurations without risking your primary operating system.

## Repository Contents

Each laboratory assignment is housed in a separate folder and includes:

- A **README** file containing a comprehensive report: the objective of the assignment, a description of the steps taken, the rationale behind each action, and the final results.
- **Screenshots** serving as evidence for key steps (e.g., command output, configuration details, and the operational status of configured services).
- Where applicable, configuration files and other relevant materials.

## Purpose

- **Reinforcing theory through practice.** Course concepts are better understood when you execute commands yourself and grasp exactly what each one does.
- **Developing documentation skills.** Properly documenting results is an essential part of engineering work; the reports in this repository are written in the same style as technical documentation for real-world projects. - **Progress history.** The repository stores all work in one place,
complete with a change history — you can always see what was done and when.

## Expected outcomes of the coursework

Completing the laboratory assignments in sequence should help you develop
practical skills in:

1. working with hypervisors and virtual machines;
2. installing and performing initial configuration of Linux systems;
3. system administration via the command line (managing packages, services, and files);
4. configuring network connections and understanding the underlying principles;
5. setting up remote access to systems, including SSH
using cryptographic keys;
6. using Git and GitHub as tools for documenting and presenting
your work.

## Repository structure

- [Laboratory No. 1](Laboratory%20No.%201/) — Laboratory Assignment No. 1: Introduction to virtual machines,
installing Debian, configuring networking (NAT, Bridged), and setting up SSH access.

This list will be updated as new assignments are added.
