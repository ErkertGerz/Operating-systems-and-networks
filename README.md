# Лабораторные работы по дисциплине «Операционные системы и сети»

Репозиторий создан для хранения и оформления лабораторных работ
по дисциплине «Операционные системы и сети». Он служит одновременно
рабочей тетрадью — здесь фиксируется ход выполнения каждой работы, —
и портфолио: по содержимому можно проследить, какие навыки
осваивались и как решались практические задачи.

## О дисциплине

«Операционные системы и сети» — дисциплина о том, как устроены и как
администрируются современные операционные системы, а также о базовых
механизмах компьютерных сетей: настройке подключений, удалённом доступе,
сетевых сервисах.

Практическая часть выполняется на виртуальных машинах: это позволяет
в безопасной среде ставить и ломать системы, экспериментировать
с сетевыми настройками и не рисковать основной рабочей системой.

## Что выкладывается в репозиторий

Каждая лабораторная работа размещается в отдельной папке и содержит:

- **README** с полным отчётом: цель работы, описание выполненных шагов,
  пояснения, зачем каждое действие было нужно, и итоги;
- **скриншоты** — доказательства выполнения ключевых шагов (вывод команд,
  конфигурация, результат работы настроенных сервисов);
- при необходимости — конфигурационные файлы и прочие материалы работы.

## Зачем это нужно

- **Закрепление теории практикой.** Темы дисциплины усваиваются надёжнее,
  когда каждая команда выполняется руками и сопровождается пониманием,
  что именно она делает.
- **Навык документирования.** Грамотное оформление результатов — часть
  инженерной работы: отчёты в этом репозитории пишутся так же, как пишется
  техническая документация в реальных проектах.
- **История прогресса.** Репозиторий хранит все работы в одном месте
  с историей изменений — всегда видно, что сделано и когда.

## К какому результату должна привести работа над дисциплиной

Последовательное выполнение лабораторных работ должно сформировать
практические навыки:

1. работы с гипервизорами и виртуальными машинами;
2. установки и первоначальной настройки Linux-систем;
3. администрирования системы через командную строку (пакеты, службы, файлы);
4. настройки сетевых подключений и понимания их принципов;
5. организации удалённого доступа к системам, в том числе по SSH
   с использованием ключей;
6. работы с Git и GitHub как инструментом фиксации и представления
   результатов.

## Структура репозитория

Список будет пополняться по мере выполнения новых работ.
